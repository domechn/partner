# Partner

Partner 是一个本地运行的桌面助手原型，目标是让用户可以一边看屏幕、一边说话来完成操作。

它把“看到你在看哪里”“理解你刚刚说了什么”“知道你屏幕上正在发生什么”放到同一个体验里，让对话不只是聊天，而是更接近真正能协作的电脑助手。

## 它能做什么

### 1. 看懂你的关注点
- 实时读取摄像头画面，跟踪你的注视位置
- 提供 5 点校准流程，帮助系统更稳定地理解你正在看哪里
- 在桌面上显示注视气泡，让关注点可视化

### 2. 支持自然对话
- 可以持续收音，进入更接近“边说边用”的对话模式
- 支持语音输入，也支持直接手动输入文字
- 对话过程中会展示实时转写、助手回复和当前状态

### 3. 更懂“你说的这个”
- 每次对话都会结合最近的摄像头画面、当前屏幕截图和注视点
- 更适合处理“点这个”“打开这个”“我在看这个页面”这类带指代的表达

### 4. 可以帮你执行电脑操作
- 支持点击、输入、切换标签页、打开应用或链接等动作
- 会先把目标拆成步骤，再逐步执行
- 遇到高风险动作会先请求确认，避免误操作

### 5. 用语音把结果回给你
- 助手不仅能返回文本，还可以直接语音播报
- 更适合在持续操作电脑时获得即时反馈

## 适合什么场景

- 一边浏览网页，一边直接说“帮我点这个”
- 在多标签页、多窗口环境里快速完成简单操作
- 希望减少鼠标和键盘切换，用更自然的方式驱动电脑
- 需要一个能结合视线、语音和屏幕上下文的本地助手原型

## 本地运行

请先安装 Node.js、Python 和 `uv`，然后执行：

```bash
npm install
cd python && uv sync && cd ..
npm run dev
```

启动后按界面提示完成摄像头校准即可开始使用。首次运行 Python 服务时会准备本地模型，可能需要多等一会儿。若在 macOS 上首次运行，可能需要授予摄像头或屏幕录制权限。
